# 0010. V1 is plan-first: plan, record (or upload), visualise

- **Status:** accepted (Raushan, 2026-10-21; PRD v0.2)
- **Tree level:** root
- **Date:** 2026-10-21

## Context
Creators stall before the camera: no plan, no script. Upload-only tools assume footage exists; AI-avatar tools replace
the creator, which audiences trust less.

## Options
1. **Upload-first visual explainer** (PRD v0.1).
2. **Plan-first**: topic + notes → plan → script on a teleprompter → creator records → visuals (chosen); upload stays.
3. **AI-presenter first** (avatar/voice by default).

## Decision
Option 2. The creator stays on camera; AI voice (V1, opt-in) and avatars (V2, opt-in) are labelled.

## Consequences
V1 grows: plan-script, record (teleprompter) and transcript-to-script alignment join the scope. New metric: share of
videos that start from a plan (≥ 40% in V1).

## How we verify
Phase 0: at least five of ten benchmark videos are made through plan → script → teleprompter by creators who started
with only a topic and notes.
